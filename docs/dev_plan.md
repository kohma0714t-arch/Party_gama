## 2. テスト計画

### 2.1 単体テスト（Vitest）
1. **物理エンジン検証 (`src/__tests__/physics.test.ts`)**
   - 通常ジャンプが5マス（200px）の段差を越えられること
   - 壁ジャンプが3マス以上上昇できること
   - コヨーテタイム（足場離脱後0.08秒後のジャンプ入力）が成立すること
   - しゃがみ状態（高さ22px）で1マス高の隙間を通過できること
   - ハチミツ付着時に移動速度が低下すること
   - バネ足場で通常ジャンプ以上の跳躍速度になること
2. **ゲーム進行・ルール検証 (`src/__tests__/simulation.test.ts`)**
   - 2人以上参加で全員ゴールした場合、`too_easy` となり全員0点になること
   - 全員死亡した場合、`no_points` となり全員0点になること
   - ソロボーナス（+0.6）、1位ボーナス（+0.2）、トラップボーナス（+0.2/キル）、コインボーナス（+0.6）、カムバック（+0.8）、ポストモーテム（+0.6）が仕様通り合算されること
   - パーティーボックスで同一インデックスを2人が同時に選んでも1人だけが取得すること
   - 爆弾配置で周囲3×3の配置済みブロックが破壊され、静的地形は壊れないこと
   - ハチミツで動くリフトに隣接させたブロックがアクション時に一緒に移動すること

### 2.2 ビルド & 静的検証
- `npx tsc --noEmit`（型エラー0）
- `npm run build`（Viteプロダクションビルド成功）

### 2.3 実ブラウザE2E動作確認
- 開発サーバー (`http://localhost:5173`) を起動し、ブラウザ上で以下を確認する：
  1. タイトル画面が表示され、日本語表記・ボタン配置に崩れがないこと。
  2. 「1人＋Botですぐ遊ぶ」またはルーム作成でツリーハウスロビーに入り、Botを追加して最大6人まで表示されること。
  3. キャラ変更・ステージ変更・ルール設定ができ、ツリーハウス内でキャラが動かせること。
  4. ゲーム開始後、パーティーボックス → ブロック配置 → アクションレース → スコア精算のサイクルが一通り動作すること。
  5. フリープレイモードで20種のブロックから選択・配置・テストラン切替が動作すること。
  6. ブラウザコンソールに未処理エラーが出ていないこと。
