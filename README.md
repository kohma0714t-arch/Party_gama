# TRICKY CRITTERS（トリッキー・クリッターズ）

Webブラウザで最大6人までオンライン対戦できる、コース自作・対戦型2Dパーティプラットフォーマーです。
各ラウンドの「ビルドフェーズ」で足場やトラップを自由に配置してコースを作り上げ、続く「アクションフェーズ」でゴールを目指して競い合います。

## 主な特徴

- **最大6人オンラインマルチプレイ**
  - PeerJS（WebRTC P2P）によるルームコード参加型のオンライン対戦に対応しています。
  - 同一ブラウザの複数タブ間では BroadcastChannel を用いたローカル通信でそのまま動作テスト・対戦が可能です。
- **コース自作 × アクションの交互進行**
  - ラウンドごとに「パーティボックス」から最大10枠のアイテムを順番に選び、40x22タイル（1600x880px）のステージに設置します。
  - 他のプレイヤーがゴールできない難所を作りつつ、自分だけは突破できる絶妙なバランスを狙います。
- **全32種類のギミック（ライブプレビュー対応）**
  - 足場系（木製ブロック、階段、動く足場、崩れる足場、氷床、ハチミツなど）、トラップ系（トゲ、回転ノコギリ、クロスボウ、大砲、有刺鉄線、ブラックホール、スイングハンマーなど）、特殊ギミック（ばね、扇風機、ワープドア、コイン、ボムなど）を収録。
  - パーティボックスや配置カーソル上では実際の挙動がアニメーション付きでプレビューされます。
- **4つの対戦ステージ + ランダム選択 + ツリーハウス広場**
  - 「のどかな農場」「高層ビルの屋上」「回転風車の丘」「灼熱の火山洞窟」の4ステージとランダム選択、および待機用「ツリーハウス広場」を搭載しています。
- **6種類のプレイアブル動物キャラクター**
  - ニワトリ、ウマ、ヒツジ、アライグマ、キツネ、カモノハシから選択でき、壁キック・コヨーテタイム・ジャンプバッファに対応した軽快なアクションが楽しめます。
- **設定集約・フルスクリーン・Web Audio 音響**
  - ルーム内のプレイヤー一覧・キャラ変更・ステージ選択・ゲームルール設定・フルスクリーン切替を設定モーダルに統合し、プレイ画面を広く保っています。

## 技術スタック

- **フロントエンド**: React 19 / TypeScript 5 / Vite 6
- **ゲーム描画・物理**: HTML5 Canvas 2D / 固定タイムステップ物理演算（60Hz）
- **通信**: PeerJS（WebRTC P2P）/ BroadcastChannel API
- **サウンド**: Web Audio API（プロシージャルBGM・効果音生成）
- **テスト**: Vitest

## セットアップ・実行方法

前提環境: Node.js（推奨 v20 以上）/ npm

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動（http://localhost:5173）
npm run dev

# 単体テスト実行（Vitest）
npm test

# 型チェックおよび本番ビルド（dist/ 出力）
npm run build

# ビルド済みアプリのプレビュー（http://localhost:4173）
npm run preview
```

## 操作方法

### アクションフェーズ / ツリーハウス広場
- **移動**: `A` / `D` または `←` / `→`
- **ジャンプ / 壁キック**: `Space` / `W` / `↑`
- **ダッシュ**: `Shift`
- **しゃがみ**: `S` / `↓`
- **ダンス**: `E` / `Q`
- （ゲームパッド入力にも対応）

### ビルド（配置）フェーズ
- **カーソル移動**: マウス移動
- **回転**: `R` キーまたは画面ボタン
- **左右反転**: `F` キーまたは画面ボタン
- **設置**: 左クリック

### その他
- **フルスクリーン切替**: 画面上の設定またはフルスクリーンボタンから切り替え可能

## マルチプレイの遊び方

1. ホーム画面から **「部屋を作る」** を選択してルームを作成します（設定画面からローカル複数タブモード／オンラインP2Pモードを切り替え可能）。
2. 発行されたルームコードを他のプレイヤーに共有し、相手は **「部屋に入る」** からコードを入力して参加します。
3. ツリーハウス広場でキャラ選択・ステージ設定（またはランダム選択）・ルール調整を行い、全員が待機エリア等で準備できたらラウンドを開始します。
